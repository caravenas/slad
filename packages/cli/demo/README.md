# demo

A SLAD agent generated by `slad create agent demo`.

```
demo/
├── slad.config.ts        # project config (provider, paths)
├── agents/
│   └── demo.agent.ts # the agent (stage → pipeline → createAgent)
├── tools/                # add tools here with `slad create tool <name>`
└── package.json
```

## Run

```bash
pnpm install
pnpm start
```

The generated agent ships with a mock model provider so it runs offline. Replace it
with `getProvider("anthropic", process.env.ANTHROPIC_API_KEY)` for a real model, and
grow the project with `slad create tool|stage|pipeline <name>`.
